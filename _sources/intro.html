🌐 Apa Itu Web Mining?#

Web Mining atau penambangan web adalah proses menerapkan teknik pengolahan data, data mining, dan machine learning untuk menemukan informasi, pola, serta pengetahuan yang bermanfaat dari berbagai sumber data di web.

Web Mining dapat digunakan untuk mengumpulkan dan menganalisis data yang berasal dari halaman website, artikel berita, dokumen online, maupun aktivitas pengguna di internet.

Secara umum, Web Mining dibagi menjadi tiga jenis utama:

  1. Web Content Mining

    Proses mengekstraksi informasi dari isi atau konten halaman web, seperti teks artikel berita, gambar, video, dan dokumen. Contohnya adalah mengambil isi berita dari website untuk dianalisis.

  2. Web Structure Mining

    Proses menganalisis struktur atau hubungan antarhalaman web berdasarkan tautan (hyperlink). Teknik ini dapat digunakan untuk mengetahui hubungan dan keterkaitan antarhalaman dalam sebuah website.

  3. Web Usage Mining

    Proses menganalisis pola perilaku pengguna berdasarkan data aktivitas mereka di web, seperti riwayat kunjungan halaman, klik, dan interaksi pengguna.

Dalam pembelajaran ini, saya akan lebih berfokus pada Web Content Mining, khususnya pengumpulan dan pengolahan teks dari website untuk menghasilkan informasi yang bermanfaat.

Melalui project ini, saya akan mengeksplorasi berbagai tahapan dalam pengolahan data web, mulai dari:

  • Text Mining: Mengolah teks untuk memperoleh informasi dan pola yang terdapat di dalamnya.

  • Penerapan Algoritma: Menggunakan metode pengolahan data dan machine learning untuk menemukan pola atau informasi dari dataset.
